# Debian references in Boswas OS: audit

Boswas OS presents itself as **Boswas OS** (ADR-0005). Debian remains the
technical base, so some references must stay. This audit lists every
place a Debian reference was found, classified as:

| Class | Meaning | Rule |
|-------|---------|------|
| USER-FACING | Shown to people using the device | Replaced with Boswas OS, unless doing so would break something (then listed under "Remaining") |
| INTERNAL | Identifiers, file names, comments, metadata nobody sees in normal use | Kept |
| LEGAL / LICENSING | Copyright and licence notices, attribution | Kept: required by the licences |
| TECHNICAL DEPENDENCY | Needed by package management, boot, Secure Boot or third-party tools | Kept |

How it was audited:

- the source repository: `grep -ri debian`, then classification;
- the built image filesystem: `/etc`, `/usr/share/{plasma,sddm,applications,metainfo,konsole,icons,wallpapers}`,
  `/etc/xdg`, Firefox's distribution files, live-config, `os-release`;
- the boot medium (`/.disk`, GRUB configuration);
- the running system (boot test screenshots and serial checks).

Automated guards keep it that way:

- `tests/static/test_sources.sh`: no Debian in user-facing sources;
- `tests/build/test_iso_contents.sh`: boot menu entries and `.disk/info`;
- `tests/packages/test_image_packages.sh`: `os-release`, banners, motd and
  the live user;
- `config/live-build/config/hooks/live/0100-boswas-verify.hook.chroot`:
  fails the build;
- `tests/boot/qemu_boot_test.py`: `os-release`, `hostnamectl` and banners
  on the running live and installed systems.

## Replaced (USER-FACING, now Boswas OS)

| Where | Before | Now |
|-------|--------|-----|
| `/etc/os-release` (`NAME`, `PRETTY_NAME`), shown by `hostnamectl`, systemd's boot status line, KDE, `lsb_release` | Debian GNU/Linux 13 (trixie) | Boswas OS v1 Alpha (`ID=boswas`, `ID_LIKE=debian`); base-files' file is diverted |
| Live image's own `/etc/os-release` copy (live-build writes it at bootstrap) | Debian GNU/Linux | Refreshed by boswas-os (keeps `IMAGE_ID`/`BUILD_ID`) |
| `/etc/issue`, `/etc/issue.net` (console and serial login) | Debian GNU/Linux 13 | Boswas OS v1 Alpha (replaced while Debian's default; restored on removal) |
| `/etc/motd` | "The programs included with the Debian GNU/Linux system…" | The same legal notice in Boswas OS wording (only while unmodified) |
| Boot menu subtitle (live/installation medium) | `Debian 13 "trixie" base` | `Live and installation medium` |
| `.disk/info` on the medium (shown by the installer, apt-cdrom) | `Debian GNU/Linux 13 "Trixie" - Snapshot amd64 LIVE/INSTALL` | `Boswas OS v1 Alpha (1.0~alpha3) - amd64 LIVE/INSTALL` |
| System Settings > About this System, "Variant" | `Based on Debian 13 "trixie"` | Nothing on installed systems; `Live session` in the live session |
| About page website button (from os-release `HOME_URL`) | debian.org | Not shown (no `HOME_URL`) |
| Live user's full name (launcher, lock screen, login list) | `Debian Live user` (live-config default) | `Boswas OS Live` |
| Boot splash | Plain console text (Debian's Plymouth theme belongs to desktop-base, not installed) | Boswas OS Plymouth theme (boot, shutdown, disk passphrase) |
| Session start-up splash | "Plasma made by KDE" (Breeze) | Boswas OS splash |
| `boswas status` AppArmor detail (Security Center) | "…(Debian skips them on live media)" | "…(they load once Boswas OS is installed)" |
| `boswas policy status` repository | "Debian upstream" | "upstream package archive" |
| Firefox ESR search engines | "Debian packages" search plugin | Removed by policy (`/usr/lib/firefox-esr/distribution/policies.json`) |

## Remaining, and why

| Where | Class | Why it stays |
|-------|-------|--------------|
| GRUB menu entries on **installed** systems ("Debian GNU/Linux"), firmware boot entry "debian", EFI directory `\EFI\debian` | TECHNICAL DEPENDENCY | Debian's Secure-Boot-signed GRUB looks for its configuration in `/EFI/debian`. Renaming it (GRUB_DISTRIBUTOR) breaks Secure Boot. Mitigation: the menu is hidden (Esc or Shift shows it, e.g. for recovery), so users do not normally see it |
| The Debian Installer's own window titles and texts ("Debian GNU/Linux installer", step names) | USER-FACING (cannot change safely) | They come from the installer's templates and cannot be changed without rebuilding the installer. Its banner, medium name and boot entries say Boswas OS. A Boswas-built installer is future work |
| Installer menu "Advanced install options" entry texts, if live-build's templates name Debian | USER-FACING (secondary) | Generated by live-build; checked by `test_iso_contents.sh` (entry titles must not name Debian) |
| Kernel release string `6.12.x+deb13-amd64` (`uname -r`, About page, terminal welcome) | TECHNICAL DEPENDENCY | The signed Debian kernel's version; changing it means rebuilding and re-signing the kernel |
| `/etc/debian_version`, `ID_LIKE=debian`, `VERSION_CODENAME=trixie`, apt sources (`deb.debian.org`), package names and versions (`~deb13u1`) | TECHNICAL DEPENDENCY | Package management, unattended security updates and third-party tools rely on them |
| `boswas-info` "Package base: Debian 13.7 (trixie)", About > Technical details, `boswas-device inventory` "package base" | TECHNICAL (labelled) | Administrators need the base release (security advisories are per release); shown only in technical details |
| `/usr/share/doc/*/copyright`, `changelog.Debian.gz`, the Open-source licences note in Control Center | LEGAL / LICENSING | Required by the licences; attribution is honest |
| AppStream metadata `org.debian.firmware_*.metainfo.xml` | INTERNAL | Package metadata; no software centre shows it (Discover is not installed) |
| SDDM alternative named `debian-theme` (points to Breeze) | INTERNAL | An alternatives link name; the theme it points to is Breeze with Boswas art |
| Breeze icon `application-vnd.debian.binary-package` | INTERNAL | MIME type name for `.deb` files |
| `/etc/firefox-esr/firefox-esr.js` comment, Firefox's internal distribution ID | INTERNAL | Not displayed in normal use |
| `/usr/lib/live/config/*` copyright headers ("Debian Live team") | LEGAL / INTERNAL | Licence headers of live-config scripts |
| Repository documentation (`docs/`), build scripts, comments | INTERNAL | Developer documentation about the build; not installed on devices |

## Not present (checked)

- Debian wallpapers, Plymouth themes, GRUB backgrounds and logos: they
  come from desktop-base, which is not installed.
- KDE's Debian-branded welcome wizard: plasma-welcome is excluded in
  `config/live-build/config/archives/boswas-exclude.pref.chroot`.
- Debian names in application menu entries: none of the visible
  applications names Debian.
